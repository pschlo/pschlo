## Hi, I’m Peter 👋

I build Python tools for scientific computing and practical automation.

**[Windsim](https://github.com/pschlo/windsim)** is my framework for wind turbine
noise prediction and mapping. Developed for my bachelor’s thesis at RWTH Aachen,
it combines acoustic modeling, geospatial data preparation, and parallel
computation with Xarray and Dask.

[Read the thesis](https://ths.rwth-aachen.de/wp-content/uploads/sites/4/thesis_Schlosshan.pdf)
